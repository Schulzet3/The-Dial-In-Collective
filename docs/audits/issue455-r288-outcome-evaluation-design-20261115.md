## Prospective opt-in evaluation concept — gated, not approved
Before any data capture or participant interaction: obtain a separate explicit owner decision covering informed consent, voluntary participation/withdrawal, the minimum proposed schema and storage/retention, RLS/Admin access, no external community aggregation, auditability and adverse-outcome visibility. The following is only a proposed acceptance method.

A pair requires an explicitly consenting participant and user-confirmed baseline shot/recommendation and next-shot linkage; two original, unmodified, separately timestamped shots of the **same coffee identity**, setup, grinder equipment version and calibration, basket, named espresso style (Turbo is not Fast-Flow), and feed mode (Slow Feed is not standard). Both records need physically valid measured dose/yield/time/grind, an actual immutable rating of **all five** taste responses, and context-specific optional temperature handling. Verify that precisely **one** genuinely controllable dimension changed intentionally (grind, yield, or enabled/available temperature); dose and all other available controllable settings remain unchanged. Measured elapsed time is generally an outcome, not a controllable adjustment. Use explicit chronological instants; ignore imported missing/invalid dates and stale/offline duplicate replay. Label remaining unknown confounders, not inferred constancy. No universal numeric tolerance for measurement rounding, coffee rest/age, cleaning, water chemistry, pressure, tamping, flow or cup temperature is established here.

Never silently credit a pair if a different coffee/roast, grinder/burr recalibration or changed basket/recipe style/feed or unsupported temperature adjustment is present; if two controls changed; if the second shot was not actually logged/rated; if the first shot is incomplete, malformed, hidden, corrected without a valid versioned pairing, or if the user declined/withdrew consent. User follow-through must be explicitly established; a copied button only documents an initial draft action and cannot prove the final intended variable was changed.

**Proposed analysis, not performed:** retain the five ordinal before/after values side by side, report per-scale direction/unchanged and pre-existing green versus new green versus worse/non-green (including adverse dryness and clarity outcomes) without collapsing them into a fabricated 0–100% confidence or claiming causal improvement. Report completeness/attrition and noncomparable cases separately rather than filtering out disappointing or missing results. Distinguish repeated shots from independent coffees/people, and observational association from randomized causal benefit. If genuine effectiveness data ultimately becomes available, any new recommendation thresholds or policy require another explicit owner decision and scoped source-bound QA.

## Proposed synthetic acceptance matrix (PLAN ONLY — NOT RUN)
| Case | Expected result if a future consented evaluator is separately authorized |
| --- | --- |
| Same coffee/hardware/style/feed/calibration; valid baseline and next; all five; grind alone changed | Eligible for qualitative paired comparison, never automatic efficacy PASS |
| Same context; yield alone changed with dose/grind/temp fixed | Eligible; time difference is an observed result |
| Temperature alone changed and equipment temperature control explicitly enabled | Eligible only if measured originals and consent/linkage are valid |
| Four tastes filled, fifth missing on either shot | Ineligible; missing is not green |
| Both shots green but no control changed | No intervention; must not miscount as improvement |
| Baseline all-green, follow-up worse on one or more scales | Record adverse sensory outcome; do not suppress |
| Coffee or roast identity changed | Ineligible, no cross-coffee attribution |
| Setup/version/calibration/basket/style changed (including Turbo vs Fast-Flow) | Ineligible |
| Feed mode toggled standard versus Slow Feed | Ineligible |
| Grind AND yield changed, or dose also changed | Ineligible: non-isolated intervention |
| Provenance only says copied starting grind/temp; no user-verified follow-through | Ineligible as proof of a followed next-shot recommendation |
| Invalid/missing timestamp, overwritten historic record, or duplicated offline ID | Ineligible or deduplicate by immutable ID, preserving originals |
| Temperature unknown/unsupported on either shot | Do not compare as a temperature intervention |
| Consent missing or withdrawn | No new collection/analysis |
