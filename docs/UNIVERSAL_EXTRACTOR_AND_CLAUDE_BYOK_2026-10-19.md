## Development implementation
- `src/server/coffee-page-metadata.mjs`: extend aliases for Spanish and French country, farm, producer, cultivar, harvest and flavor details; combine existing structured/page-specific extraction with scoped narrative, blend and espresso modules; expose only bounded product text to authenticated preview when explicitly requested; improve slug-form roaster presentation without brand/lot inference.
- `src/server/coffee-narrative-evidence.mjs`: inspect current-product headings/paragraphs after the selected H1, strip SVG/scripts/nav/related products, infer a named farm/country and separately identified human growers when explicitly stated, recognize corroborated carbonic/anaerobic stages and selected coffee variety/elevation with source evidence. Generic producer groups are **not people**; generic education does not supply a process fact.
- `src/server/coffee-blend-evidence.mjs`: exact multi-component percentage lists; preserve fractions/lots as supplementary details, withhold single origin/process if the blend components differ.
- `src/server/coffee-espresso-evidence.mjs`: additional explicitly headed espresso parameter reference extractor; preserve roaster's published dose, +/- tolerance, output/time ranges and source temperature guidance without guessing Fahrenheit or confusing pour-over recommendations with espresso.
- `src/server/coffee-product-layouts.mjs`: reject generic picking/sorting headings as processing detail without processing evidence.
- `src/server/coffee-semantic-source.mjs` and `netlify/functions/coffee-url-preview.mjs`: optional **source-only, public, 9KB max** selected-product text in the **already authenticated/admitted and quota-claimed** preview response; this text is never saved as coffee or user data and is inaccessible anonymously.

Without key/opt-in no AI request. A live Anthropic call cannot be verified without a user key.
- `site/cloud/main.js`: collapsed advanced Settings key entry/Forget and explicit opt-in; URL Autofill immediately shows deterministic form suggestions, then optionally enriches only still-empty values even if the user edits while the model runs. This keeps the **approved one-click** workflow.
- `site/cloud/coffee-url-autofill.js`: review-only supplementary sources including farms, grower, blend components, output/dose/time ranges and escaped Claude evidence.
- `build_cloud.mjs`: static browser bundle allowlist and minimal CSP `https://api.anthropic.com` connect-src, no other external script. Browser QA synthetic module bundle updated.
- Synthetic + real-page regressions: `tests/coffee-narrative-evidence.test.mjs`, `tests/coffee-multi-roaster-depth.test.mjs`, `tests/coffee-claude-local-byok.test.mjs`, updated `tests/browser/cloud_owner_qa.py` and `scripts/audit/coffee-roaster-live-probe.mjs`.
