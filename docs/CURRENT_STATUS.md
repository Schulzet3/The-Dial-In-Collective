## New development tranche — contextual outlier validation and in-app Confirm / Correct (2026-10-18 UTC)

**Owner directive:** Implement the recommended replacement for the arbitrary 4× median time cutoff, and provide an in-app confirm/correct prompt only for genuinely flagged, Dialed-In shots. **Development implementation and synthetic tests PASS; this code has not been deployed to production.** Research/provenance and configurable heuristics are documented in [Community Outlier Research](COMMUNITY_OUTLIER_RESEARCH_2026-10-18.md) and [issue #9](https://github.com/Schulzet3/The-Dial-In-Collective/issues/9#issuecomment-6246537438).

**Backend:** Forward-only staged migration [`20261018061030_dic_contextual_quality_community_ui.sql`](../supabase/migrations/20261018061030_dic_contextual_quality_community_ui.sql) replaces the earlier relative time/ratio cutoffs with a *potential-outlier flag* based on the robust median and scaled MAD (modified Z >3.5), practical absolute/relative floors and a minimum of **5 comparable own prior shots** or **5 distinct exact coffee/style contributors**. These numeric floors are **conservative unvalidated engineering heuristics**, *not espresso extraction windows*. An unusual shot remains Dialed In and can be user-confirmed; identity/revision/fingerprint checks, verified coffee, all-green taste and privacy constraints remain. New authenticated, membership- and owner-gated outlier inbox `dic_my_community_outliers` supplies only the owner's pending flags. A sanitized member-only `dic_browse_community_shots` supports the separately staged Community tab without notes/account identifiers. The existing `dic_confirm_community_outlier` handles approval, bound to source revision.

**Frontend:** [Community views](../site/cloud/community.js), [cloud client](../site/cloud/client.js), [app](../site/cloud/main.js), [styles](../site/styles.css) and explicit [build allowlist](../build_cloud.mjs). The prompt appears unobtrusively after sync **only for held extreme outliers** and offers **Yes, It's Correct**, **Correct Shot** (opens existing Edit Shot form, no write until Save) and **Later** (session/revision-scoped dismissal). No blocking prompt for normal shots; no changes to Log Shot → Rate → Recommendation, private notes, or account separation. The Community browsing code is staged but **not published**; #10 recipe families and #12 full community recommendation integration remain open.
