Authenticating sessions (short-lived bearer tokens + refresh) are different from permanent membership.

The new portal and server admin member mutation **cannot remove any administrator**. Existing accounts have zero automatic expiration.

| `private.dic_admin_issue_invite` / `public.dic_admin_issue_invite` | Cryptographic PostgreSQL built-in v4 UUIDs x2 (~244 bits unpredictability) generate `dic-` + 64 lowercase hex. Saves **SHA256(token)** only; plaintext returned **one time** to signed-in admin's in-memory page and copy button, never stored in localStorage, logs or GitHub. All **new** codes have `expires_at=NULL` (no expiry). Admin can choose 1 use (default), 5 uses, unlimited. Validates 1..100 for explicitly provided finite values; global 50-active-code operational guard/serializes creation. |
| `private.dic_admin_revoke_invite` | Immediately sets `revoked_at`, idempotent. Never impacts existing admitted accounts or contributed data. No plaintext tokens returned. |
| `private.dic_admin_set_member_access` | Toggle only **previously admitted regular members'** `private.beta_members.enabled`; `private.app_admins` protects **all** administrators plus a self-owner check. Current RLS and member RPCs recheck `private.is_member`, so revocation blocks protected app data without deleting `auth.users`, old shots/notes or immutable Community contributions. Restore validates verified email. This is **not hard deletion** or forced revocation of existing Supabase Auth access tokens. |
| Frontend `site/admin/main.js`, `site/admin/view.js`, `site/admin/styles.css` | Compact private operator portal with Create Code/Copy once/usage selection, list/revoke, existing member management and protected permanent Administrator badge. Existing pending-coffee review dashboard remains read-only. Password/role data not cached in this page. Auth account switch/signout immediately removes token/UI; RPC denies bypass even if client DOM/metadata forged. |
| Security source | Private tables: RLS + no client access/grants. Public RPC wrapper: `security invoker`, narrow EXECUTE authenticated only; inner `security definer set search_path=''` with mandatory server admin check. Access changes have no-secret admin audit receipts. Existing member invite redemption row-lock/rate-limit and revocation checks unmodified. |
